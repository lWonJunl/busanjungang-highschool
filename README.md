## 💡 Learning & Project Highlights

### Python Foundations

* 변수와 표준 입출력부터 조건문, 반복문, 배열과 함수까지 단계적으로 실습했습니다.
* 작은 콘솔 프로그램을 만들며 입력, 처리와 출력이 연결되는 프로그램 구조를 익혔습니다.
* Turtle 그래픽을 통해 좌표와 반복문을 시각적인 결과물로 표현했습니다.

### Data Analysis

* 공공데이터의 열, 자료형과 결측값을 확인하고 분석 목적에 맞게 정리했습니다.
* 불쾌지수 공식을 코드로 옮기고 월별 기상 환경을 비교했습니다.
* 인구와 태풍 데이터를 표와 그래프로 표현하며 데이터 해석 방법을 익혔습니다.

### Machine Learning

* 데이터를 학습용과 평가용으로 나누고 회귀 모델을 학습했습니다.
* 서울 기온, 공공자전거 수요와 물가 변화처럼 실생활과 연결된 주제를 다뤘습니다.
* 예측 결과와 인과관계를 구분하고 데이터 범위에 따른 한계를 함께 검토했습니다.

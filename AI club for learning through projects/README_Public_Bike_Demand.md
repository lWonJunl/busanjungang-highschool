# 공공자전거 수요 예측

공공자전거 데이터를 학습용과 평가용으로 나누고 수요를 예측하는 머신러닝 흐름을 구현한 프로젝트입니다.

## 주요 작업

- 데이터의 열과 자료형을 확인하고 모델 입력 형태로 전처리했습니다.
- 데이터를 훈련 세트와 평가 세트로 분리했습니다.
- 예측 모델을 학습하고 평가 데이터의 수요를 추정했습니다.
- 예측값과 실제값을 비교하며 모델 평가의 의미를 익혔습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Scikit-learn` · `Prediction`

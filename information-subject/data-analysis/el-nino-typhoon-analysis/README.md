# 🌀 엘니뇨·라니냐와 태풍 강도 분석

> 1990년부터 2023년까지의 태풍 자료를 이용해 엘니뇨·라니냐 시기와 태풍 강도 지표의 관계를 비교한 정보 교과 탐구 프로젝트입니다.

기상청 과거 태풍 정보에서 최저 중심기압과 최대풍속을 수집하고, 연도를 엘니뇨·라니냐·일반 시기로 구분한 뒤 그룹별 평균과 그래프를 비교했습니다.

<br>

## 📂 Overview

| Item | Description |
| :-- | :-- |

| **Period of Data** | 1990 ~ 2023 |

<br>

## 🎯 탐구 질문

* 해수면 온도가 높은 엘니뇨 시기의 태풍은 평상시보다 강한가?
* 해수면 온도가 낮은 라니냐 시기에는 어떤 차이가 나타나는가?
* 최저 중심기압과 최대풍속을 이용해 태풍 강도를 비교할 수 있는가?

<br>

## 📖 핵심 개념

| Concept | Description |
| :-- | :-- |
| **엘니뇨** | 열대 동·중태평양 해수면 온도가 평년보다 높은 상태가 지속되는 현상 |
| **라니냐** | 같은 지역의 해수면 온도가 평년보다 낮은 상태가 지속되는 현상 |
| **최저 중심기압** | 값이 낮을수록 강한 태풍으로 해석하는 지표 |
| **최대풍속** | 값이 높을수록 강한 태풍으로 해석하는 지표 |

<br>

## 📊 데이터 수집

`typhoon_data_collection.ipynb`에서는 Requests와 BeautifulSoup으로 기상청 태풍 이력 페이지를 읽고 연도·태풍 번호별 최저기압과 최대풍속을 추출하는 과정을 기록했습니다.

분석 노트북은 수집 결과를 정리한 `TY_1990-2023.csv`를 Google Colab에서 업로드해 사용합니다. CSV는 저장소에 포함하지 않았으며 분석에는 다음 열을 사용했습니다.

| Original Column | Analysis Column | Role |
| :-- | :-- | :-- |
| `태풍번호` | `태풍번호` | 발생 연도와 태풍 식별 |
| `최저 기압(hpa)` | `최저기압` | 태풍 강도 비교 |
| `최대풍속(10분 평균 m/s)` | `최대풍속` | 태풍 강도 비교 |

<br>

## 🔄 분석 과정

```text
기상청 태풍 이력 수집
        ↓
1990~2023년 CSV 구성
        ↓
분석 열 선택 및 이름 정리
        ↓
발생 연도를 E / L / N으로 구분
        ↓
그룹별 최저기압·최대풍속 평균 계산
        ↓
막대그래프로 비교
        ↓
결과와 해석의 한계 정리
```

분석 노트북은 태풍 번호의 연도 구간을 기준으로 다음 값을 직접 부여합니다.

| Label | Meaning |
| :--: | :-- |
| `E` | 엘니뇨 시기 |
| `L` | 라니냐 시기 |
| `N` | 그 외 일반 시기 |

<br>

## 📈 분석 결과

* 그룹별 평균 최저기압을 막대그래프로 비교했습니다.
* 그룹별 평균 최대풍속을 별도의 막대그래프로 비교했습니다.
* 탐구 보고서에서는 엘니뇨 시기의 태풍이 평균적으로 강하고 라니냐 시기는 상대적으로 약한 경향을 관찰했습니다.

이 결과는 해당 기간과 분류 방식에서 나타난 연관성입니다. 엘니뇨가 개별 태풍의 강도를 직접 결정한다고 단정한 인과 분석은 아닙니다.

<br>

## ⚠️ 분석 범위와 한계

* 엘니뇨·라니냐 연도를 노트북의 조건문으로 직접 분류했습니다.
* 태풍 강도에 영향을 미치는 이동 경로, 해양 열용량, 대기 환경 등 다른 변수는 포함하지 않았습니다.
* 데이터 수집 노트북 출력에는 일부 페이지를 찾지 못한 오류 기록이 남아 있습니다.
* 2023년 데이터는 탐구 수행 시점까지 공개된 태풍만 포함했을 수 있습니다.
* 그룹별 평균 비교만으로 통계적 유의성이나 인과관계를 확인하지는 않았습니다.

# 🌡️ 월별 불쾌지수 분석

> 기온과 상대습도를 이용해 월별 불쾌지수를 계산하고, 불쾌감이 높은 시기를 찾는 정보 교과 데이터 분석 프로젝트입니다.

KOSIS 기상개황 자료에서 필요한 열을 선택하고 불쾌지수 공식을 적용한 뒤, 단계별 분류와 그래프를 통해 연중 변화를 비교했습니다.

<br>

## 🎯 분석 질문

* 월별 평균기온과 평균상대습도로 불쾌지수를 계산할 수 있는가?
* 불쾌지수가 `높음` 이상인 달은 언제인가?
* 기온·습도와 불쾌지수의 연중 변화는 어떤 모습인가?

<br>

## 📊 사용 데이터

원본 `기상개황.csv`에서 다음 열을 사용했습니다.

| Original Column | Analysis Column | Role |
| :-- | :-- | :-- |
| `월별(1)` | `월별` | 월 구분 |
| `평균기온 (℃)` | `평균기온` | 건구온도 `Ta` |
| `평균상대습도 (%)` | `평균상대습도` | 상대습도 `RH` |

원본 CSV는 현재 저장소에 포함되어 있지 않아 노트북 실행 시 Google Colab에서 직접 업로드해야 합니다.

<br>

## 🧮 불쾌지수 계산

노트북에서는 다음 공식을 사용합니다.

```text
DI = 0.81 × Ta + 0.01 × RH × (0.99 × Ta - 14.3) + 46.3
```

| Symbol | Meaning |
| :--: | :-- |
| `DI` | 불쾌지수 |
| `Ta` | 평균기온 |
| `RH` | 평균상대습도 |

계산된 값은 다음 기준으로 분류했습니다.

| Discomfort Index | Level |
| :--: | :--: |
| `80 이상` | 매우높음 |
| `75 이상 80 미만` | 높음 |
| `68 이상 75 미만` | 보통 |
| `68 미만` | 낮음 |

<br>

## 🔄 분석 과정

```text
기상개황 CSV 업로드
        ↓
열과 자료형 확인
        ↓
월·평균기온·평균상대습도 선택
        ↓
열 이름 단순화
        ↓
불쾌지수 계산 및 단계 분류
        ↓
75 이상인 월 추출
        ↓
기온·습도·불쾌지수 시각화
```

`np.where()`와 리스트 조건식을 모두 사용해 기온 구간을 분류하는 방법도 비교했습니다.

<br>

## 📈 시각화

* 평균기온과 평균상대습도는 선 그래프로 표시했습니다.
* 월별 불쾌지수는 막대그래프로 함께 표현했습니다.
* 한 그래프에서 세 지표의 변화 시점을 비교할 수 있도록 제목, 범례와 한글 폰트를 설정했습니다.

<br>

## ⚠️ 분석 범위와 한계

* 월평균 자료를 사용하므로 하루 중 시간대별 체감 차이는 반영하지 않습니다.
* 불쾌지수는 기온과 습도를 중심으로 한 지표이며 바람, 일사량과 개인차는 포함하지 않습니다.
* 원본 데이터 파일이 저장소에 없어 완전한 재실행에는 별도 다운로드가 필요합니다.

# 👥 인구 데이터 시각화

> 연령별·성별 인구 데이터를 가공해 전국과 제주 지역의 인구 구조를 비교한 정보 교과 데이터 시각화 실습입니다.

많은 수치가 들어 있는 CSV에서 필요한 범위를 선택하고, 남녀 인구 차이를 그래프로 표현해 어느 연령대에서 차이가 크게 나타나는지 확인했습니다.

## 🎯 분석 질문

* 전국의 연령별 남녀 인구 분포는 어떻게 다른가?
* 특정 지역만 선택해 같은 방식으로 비교할 수 있는가?
* 제주에서 남녀 인구 차이가 가장 큰 나이는 몇 살인가?

<br>

## 📊 사용 데이터

`korea_pop.csv`에는 지역별·연령별 남녀 인구수가 포함되어 있습니다.

```python
pd.read_csv("korea_pop.csv", encoding="cp949", thousands=",")
```

한글 CSV를 읽기 위해 `cp949` 인코딩을 지정하고, 천 단위 쉼표를 제거해 인구수를 숫자로 처리했습니다. 원본 데이터는 저장소에 포함하지 않았으므로 재실행할 때 행정안전부 주민등록 인구통계에서 자료를 내려받아 `korea_pop.csv`라는 이름으로 Google Colab에 업로드해야 합니다.

<br>

## 🔄 분석 과정

```text
인구 CSV 업로드
      ↓
열 구조와 지역명 확인
      ↓
연령별 남자·여자 인구 추출
      ↓
전국 분포 시각화
      ↓
제주 지역 데이터 선택
      ↓
연령별 남녀 차이 계산
      ↓
차이가 가장 큰 연령 탐색
```

<br>

## 📈 시각화와 분석

### 전국 인구 구조

연령을 축으로 두고 남자와 여자 인구수를 서로 반대 방향에 표시해 전체 인구 구조를 비교했습니다. 이를 통해 특정 연령대의 인구 규모와 성별 차이를 한눈에 확인할 수 있습니다.

### 남녀 인구 차이

연령별로 남자 인구수와 여자 인구수의 차를 계산하고 빨간색 막대그래프로 표현했습니다.

### 제주 지역 비교

전체 데이터에서 제주 지역만 선택한 뒤 같은 분석을 반복했습니다. 차이가 가장 큰 값의 인덱스를 찾아 남자가 더 많은 나이와 여자가 더 많은 나이를 각각 출력했습니다.

<br>

## ⚠️ 분석 범위와 한계

* 한 시점의 인구 자료를 사용하므로 시간에 따른 변화는 분석하지 않습니다.
* 지역별 인구 규모가 다르므로 단순 인원 차이만으로 지역 특성을 일반화하기 어렵습니다.
* 원본 `korea_pop.csv`가 저장소에 없어 전체 과정을 재실행하려면 데이터를 별도로 준비해야 합니다.
* 노트북은 Google Colab의 파일 업로드와 한글 폰트 설정을 전제로 작성되었습니다.

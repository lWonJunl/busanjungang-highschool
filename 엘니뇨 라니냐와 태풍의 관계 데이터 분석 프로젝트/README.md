# 엘니뇨·라니냐와 태풍 분석

1990년부터 2023년까지의 태풍 데이터를 전처리하고 엘니뇨·라니냐와 태풍 강도의 관계를 살펴본 기상 데이터 분석 프로젝트입니다.

## 주요 작업

- 기상청 태풍 데이터의 연도, 발생 위치와 강도 관련 변수를 확인했습니다.
- 분석에 필요한 열을 선택하고 결측값과 자료형을 정리했습니다.
- 엘니뇨·라니냐 시기와 일반 시기의 태풍 특성을 비교했습니다.
- 해수면 온도 현상과 태풍 강도 사이의 관계를 표와 그래프로 시각화했습니다.
- 제한된 변수만으로 인과관계를 단정하지 않고 분석 범위와 한계를 함께 정리했습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Data Visualization` · `Weather Data`

## 배운 점

장기간의 기상 데이터를 일관된 기준으로 정리하고, 자연현상의 관계를 데이터로 비교하면서 결과와 인과 해석을 구분하는 태도를 익혔습니다.

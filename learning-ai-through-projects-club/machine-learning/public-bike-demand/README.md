# 🚲 서울 공공자전거 수요 예측

> 요일, 평균기온과 강수량을 이용해 서울시 공공자전거의 일별 대여 건수를 예측한 AI 동아리 머신러닝 프로젝트입니다.

공공자전거를 수요에 맞게 배치한다는 문제를 정의하고, 범주형 요일을 원-핫 인코딩한 뒤 선형 회귀 모델을 학습·평가했습니다.

<br>

## 📂 Overview

| Item | Description |
| :-- | :-- |
| **Activity** | AI 프로젝트 동아리 |
| **Problem Type** | Regression |
| **Model** | Scikit-learn `LinearRegression` |
| **Input Features** | 요일, 평균기온, 강수량 |
| **Target** | 일별 공공자전거 대여 건수 |
| **Samples** | 455 rows |
| **Stored Test R²** | 약 0.589 |

<br>

## 🎯 문제 정의

공공자전거는 시민의 이동 편의와 교통·환경 문제 개선을 위한 공공 서비스입니다. 필요한 장소에 자전거를 배치하려면 수요를 미리 추정할 필요가 있으므로, 날씨와 요일을 이용해 서울시 전체 대여 건수를 예측하는 문제로 구성했습니다.

<br>

## 📊 사용 데이터

노트북은 2018년 1월부터 2019년 3월까지의 자료를 사용합니다. 코로나19가 이용량에 미친 영향을 피하기 위해 2020년 이후는 분석 범위에서 제외했습니다.

| Feature | Type | Description |
| :-- | :-- | :-- |
| 요일 | 범주형 | 월요일~일요일 |
| 평균기온 | 수치형 | 해당 날짜의 평균기온 |
| 강수량 | 수치형 | 해당 날짜의 강수량 |
| 대여건수 | 수치형 | 모델이 예측할 목표값 |

원본 `seoul_rent_bike.csv`는 현재 저장소에 포함되어 있지 않습니다.

<br>

## 🔄 머신러닝 과정

```text
공공자전거·기온·강수 데이터 수집
        ↓
결측값을 0으로 처리
        ↓
기온·강수량과 대여건수 관계 시각화
        ↓
요일별 평균 대여건수 비교
        ↓
요일 원-핫 인코딩
        ↓
9개 입력 특성과 대여건수 분리
        ↓
훈련 80% / 평가 20% 분할
        ↓
선형 회귀 학습·평가·예측
```

<br>

## 🧩 데이터 전처리

요일은 숫자의 크기 관계가 없는 범주형 값이므로 7개의 열로 원-핫 인코딩했습니다. 여기에 평균기온과 강수량을 더해 총 9개 특성을 모델 입력으로 사용했습니다.

```text
금 목 수 월 일 토 화 평균기온 강수량
```

전체 455개 행은 저장된 실행에서 학습용 364개, 평가용 91개로 나뉘었습니다.

<br>

## 📈 모델 평가

노트북에 저장된 한 실행의 결정계수는 다음과 같습니다.

| Dataset | R² |
| :-- | :--: |
| Train | 약 `0.5893` |
| Test | 약 `0.5891` |

실제 대여 건수와 예측값을 산점도로 표시하고 `y = x` 기준선과 비교했습니다. 값이 기준선에 가까울수록 예측과 실제가 비슷하다는 의미입니다.

<br>

## 🔮 예측 예시

사용자가 요일, 평균기온과 강수량을 입력하면 같은 원-핫 인코딩 형식으로 변환해 대여 건수를 예측합니다.

노트북에 저장된 예시:

```text
요일: 목요일
평균기온: 30℃
강수량: 0
예상 대여 건수: 47,408대
```

<br>

## ⚠️ 모델의 한계

* 원본 `seoul_rent_bike.csv`가 저장소에 없어 그대로 재실행할 수 없습니다.
* 대여소 위치, 시간대, 휴일, 미세먼지와 행사 등 다른 수요 요인을 포함하지 않습니다.
* 결측값을 모두 0으로 바꾸는 방식이 실제 의미와 다를 수 있습니다.
* 데이터 분할에 `random_state`가 없어 다시 실행하면 평가값이 달라질 수 있습니다.
* 선형 회귀는 날씨와 수요 사이의 복잡한 비선형 관계를 충분히 표현하지 못할 수 있습니다.

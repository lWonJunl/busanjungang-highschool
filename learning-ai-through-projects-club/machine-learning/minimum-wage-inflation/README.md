# 📈 최저임금과 물가 상승률 예측

최저임금과 소비자물가지수의 관계를 확인하고, 선형 회귀 모델을 이용해 특정 최저임금 수준에서의 물가지수를 추정한 프로젝트입니다. 두 지표의 연도별 변화를 시각화한 뒤 회귀 모델을 학습하고, 결과를 물가 상승률 형태로 해석했습니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 분석 주제 | 최저임금과 소비자물가지수의 관계 |
| 사용 데이터 | 연도별 최저임금·소비자물가지수 34건 |
| 입력 변수 | 최저임금 |
| 예측 대상 | 소비자물가지수 |
| 사용 모델 | 선형 회귀 (`LinearRegression`) |
| 저장된 테스트 결정계수 | 약 `0.8860` |

## 탐구 질문

- 최저임금과 소비자물가지수는 시간에 따라 어떤 변화를 보이는가?
- 최저임금 하나만으로 소비자물가지수의 변화를 어느 정도 설명할 수 있는가?
- 학습한 회귀식으로 특정 최저임금에서의 물가 수준을 어떻게 추정할 수 있는가?

## 데이터 구성

노트북은 `소비자물가지수_최저임금.csv`를 CP949 인코딩으로 불러옵니다. 원본 CSV는 저장소에 포함하지 않았으며, 저장된 노트북의 출력에서 당시 사용한 데이터와 분석 결과를 확인할 수 있습니다. 처음부터 재실행하려면 같은 열 구성을 가진 파일을 해당 이름으로 Google Colab에 업로드해야 합니다.

| 열 | 의미 |
| --- | --- |
| `시점` | 관측 연도 |
| `물가지수` | 해당 연도의 소비자물가지수 |
| `최저임금` | 해당 연도의 최저임금 |

전체 34개 관측값 중 `최저임금`을 입력값으로, `물가지수`를 정답값으로 사용했습니다.

## 분석 과정

### 1. 두 지표의 변화 비교

연도별 소비자물가지수와 최저임금은 값의 단위와 범위가 서로 다릅니다. 이를 한 그래프에서 비교하기 위해 이중 y축을 사용했습니다.

- 왼쪽 y축: 소비자물가지수
- 오른쪽 y축: 최저임금
- x축: 연도

### 2. 학습 데이터 구성

```python
X = df2.drop(['물가지수'], axis=1)
y = df2['물가지수']
```

데이터의 70%는 학습용, 30%는 테스트용으로 분리했습니다. 저장된 실행 결과를 기준으로 학습 데이터는 23건, 테스트 데이터는 11건입니다.

### 3. 선형 회귀 모델 학습

최저임금과 물가지수의 관계를 하나의 직선으로 나타내는 선형 회귀 모델을 사용했습니다.

```python
model = LinearRegression()
model.fit(X_train, y_train)
```

모델은 최저임금이 변할 때 물가지수가 어떤 방향과 크기로 변하는지를 데이터에서 학습합니다.

### 4. 모델 평가

노트북에 저장된 실행 결과의 결정계수는 다음과 같습니다.

| 데이터 | 결정계수 R² |
| --- | ---: |
| 학습 데이터 | 약 `0.8463` |
| 테스트 데이터 | 약 `0.8860` |

R²는 모델이 데이터의 변화를 얼마나 설명하는지 나타내는 값입니다. 다만 이 프로젝트에서는 표본이 34건뿐이고 입력 변수도 최저임금 하나이므로, 높은 점수만으로 실제 물가의 원인을 충분히 설명한다고 볼 수는 없습니다.

## 예측 예시

노트북에서는 최저임금이 `9,000원`일 때의 물가지수를 예측했습니다. 저장된 실행 결과를 2020년 기준 지수 100에서의 상승분으로 표현하면 다음과 같습니다.

```text
(2020년 대비) 예상 물가 상승률: 약 13.33%
```

이 값은 학습 데이터에서 나타난 선형 관계를 연장한 추정치이며, 실제 물가 상승률을 확정적으로 예측한 결과는 아닙니다.

## 해석할 때 주의할 점

- 최저임금과 물가지수가 함께 상승하더라도 한 변수가 다른 변수의 직접적인 원인이라고 단정할 수 없습니다.
- 물가는 금리, 환율, 원자재 가격, 경기 상황 등 여러 요인의 영향을 받습니다.
- 데이터가 34건으로 적어 새로운 데이터가 추가되면 회귀식과 평가값이 크게 달라질 수 있습니다.
- 데이터 분할에 `random_state`가 지정되지 않아 노트북을 다시 실행할 때 평가값이 달라질 수 있습니다.
- 예측값에서 100을 빼 상승률로 표시하는 방식은 소비자물가지수의 기준연도가 2020년이고 기준값이 100이라는 전제에 의존합니다.

따라서 이 프로젝트는 최저임금만으로 물가를 단정하는 모델이라기보다, 두 경제 지표의 관계를 회귀 분석으로 탐색해 본 학습 프로젝트로 보는 것이 적절합니다.

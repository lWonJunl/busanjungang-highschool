# 🌡️ 2030년 서울 평균기온 예측

> 1907~2018년 서울 기온 자료와 선형 회귀를 이용해 미래 연평균기온을 예측한 AI 동아리 머신러닝 프로젝트입니다.

장기 기온 데이터의 결측값을 정리하고 실제 변화와 회귀선을 비교한 뒤, 학습된 직선 모델로 2030년과 이후 연도의 평균기온을 추정했습니다.

<br>

## 📂 Overview

| Item | Description |
| :-- | :-- |
| **Activity** | AI 프로젝트 동아리 |
| **Problem Type** | Regression |
| **Model** | Scikit-learn `LinearRegression` |
| **Input Feature** | 연도 |
| **Target** | 서울 연평균기온 |
| **Data Period** | 1907 ~ 2018 |
| **Stored 2030 Prediction** | 약 12.87℃ |

<br>

## 🎯 문제 정의

기상청의 장기 관측자료에서 연도에 따른 서울 평균기온의 변화 경향을 학습하고, 선형 회귀 모델이 미래 연도의 기온을 어떻게 예측하는지 확인합니다.

이 프로젝트의 목적은 정확한 기후 예측 시스템을 만드는 것보다 데이터 수집, 전처리, 학습과 예측으로 이어지는 머신러닝 흐름을 경험하는 데 있습니다.

<br>

## 📊 사용 데이터

`seoul_temp.csv`에는 다음 열이 포함되어 있습니다.

| Column | Role |
| :-- | :-- |
| `년` | 모델 입력 특성 |
| `평균기온` | 예측 목표값 |
| `최고기온` | 탐색적 시각화 |
| `최저기온` | 탐색적 시각화 |

노트북에서 결측 행을 제거한 뒤 연도와 평균기온 107개를 모델 학습에 사용했습니다.

원본 CSV는 저장소에 포함하지 않았습니다. 전체 과정을 다시 실행하려면 1907~2018년 서울 기온 자료를 `seoul_temp.csv`라는 이름으로 Google Colab에 업로드해야 합니다. 저장된 노트북에는 당시의 실행 결과가 남아 있습니다.

<br>

## 🔄 머신러닝 과정

```text
기상청 CSV 업로드
      ↓
자료형·통계·결측값 확인
      ↓
결측 행 제거
      ↓
최고·평균·최저기온 시각화
      ↓
연도 X와 평균기온 y 구성
      ↓
시간 순서를 유지해 학습·평가 데이터 분리
      ↓
선형 회귀 모델 학습
      ↓
미래 연도의 평균기온 예측
```

`train_test_split(..., shuffle=False)`를 사용해 과거 자료가 학습 구간, 이후 자료가 평가 구간이 되도록 시간 순서를 유지했습니다.

<br>

## 🤖 모델

전체 기간을 이용한 모델은 다음 형태의 직선을 학습했습니다.

```text
예상 평균기온 = 0.01962474 × 연도 - 26.97021952
```

노트북에는 전체 기간 외에도 이전 50년과 최근 50년 자료로 별도 모델을 만들어 추세가 학습 구간에 따라 어떻게 달라지는지 비교하는 실습이 포함되어 있습니다.

<br>

## 📈 저장된 결과

* 전체 모델이 계산한 2030년 평균기온은 약 `12.87℃`입니다.
* 실행 예시에서 2050년을 입력했을 때 약 `13.26℃`가 출력되었습니다.
* 1907~2018년 실제값과 1907~2050년 예측선을 한 그래프에 표시했습니다.
* 전체 기간, 과거 50년과 최근 50년 모델의 기울기를 비교했습니다.

## ⚠️ 모델의 한계

* 연도 하나만 입력으로 사용해 온실가스, 도시화, 해양과 대기 변화 등 다른 요인을 반영하지 않습니다.
* 장기 기온 변화가 계속 직선 형태로 이어진다고 가정합니다.
* 2030년 예측값은 기후학적 공식 전망이 아니라 학습용 단순 회귀 결과입니다.
* 연평균 자료는 계절·월·일별 변동을 설명하지 않습니다.
* 학습 기간을 다르게 선택하면 회귀선의 기울기와 미래 예측값이 달라집니다.

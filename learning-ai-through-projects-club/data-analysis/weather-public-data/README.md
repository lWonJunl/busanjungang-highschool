# ☀️ 기상 공공데이터 처리

> 서울의 연도별 최고·평균·최저기온 데이터를 정제하고 조건별로 조회하며 변화 추이를 시각화한 AI 동아리 데이터 분석 실습입니다.

Pandas로 공공데이터의 구조와 결측값을 확인하고, 필요한 행과 열을 선택한 뒤 여러 선 그래프로 장기간의 기온 변화를 비교했습니다.

## 🎯 학습 목표

* 표 형태의 공공데이터를 Pandas DataFrame으로 읽을 수 있는가?

* 열·행·조건 선택을 이용해 원하는 기온 자료를 찾을 수 있는가?

<br>

## 📊 사용 데이터

`seoul_temp.csv`에는 연도별 서울 기온 자료가 들어 있습니다.

| Column | Role |
| :-- | :-- |
| `년` | 관측 연도 |
| `평균기온` | 연평균기온 |
| `최고기온` | 해당 연도의 최고기온 |
| `최저기온` | 해당 연도의 최저기온 |

한글 CSV를 읽기 위해 `cp949` 인코딩을 사용했습니다. 원본 데이터는 저장소에 포함하지 않았으므로 노트북을 다시 실행할 때 `seoul_temp.csv`라는 이름으로 Google Colab에 업로드해야 합니다.

<br>

## 🔄 데이터 처리 과정

```text
CSV 업로드 및 읽기
      ↓
앞부분·열·자료형 확인
      ↓
열별 결측값 개수 확인
      ↓
뒤의 값으로 결측값 채우기
      ↓
필요한 열과 행 선택
      ↓
연도·기온 조건 검색
      ↓
기온 변화와 연교차 시각화
```

노트북에서는 `fillna(method='bfill')`을 이용해 빈 값을 뒤의 관측값으로 채우는 방법을 실습했습니다.

<br>

## 🔍 주요 분석

### 데이터 선택

* `년`, `평균기온`처럼 필요한 열만 선택했습니다.
* 슬라이싱으로 특정 기간의 행을 조회했습니다.
* 2000년 이후이면서 평균기온이 13℃를 넘는 연도를 조건식으로 찾았습니다.

### 기온 변화 시각화

* 전체 기간의 연평균기온을 선 그래프로 표현했습니다.
* 최고·평균·최저기온을 서로 다른 색으로 한 그래프에 표시했습니다.
* 2000년 이후의 자료만 따로 선택해 최근 흐름을 비교했습니다.

### 연교차 분석

`최고기온 - 최저기온`으로 새로운 `기온차` 열을 만들고, 연도별 변화와 값이 큰 순서를 확인했습니다.

<br>

## ⚠️ 분석 범위와 한계

* 뒤의 값으로 결측치를 채우면 실제 관측되지 않은 기간에 편향이 생길 수 있습니다.
* 연평균 자료만으로 계절별·일별 변동을 설명할 수는 없습니다.
* 원본 `seoul_temp.csv`가 저장소에 없어 전체 과정을 재실행하려면 데이터를 별도로 준비해야 합니다.
* Google Colab 한글 폰트 설치 명령은 로컬 Jupyter 환경에서 그대로 동작하지 않을 수 있습니다.

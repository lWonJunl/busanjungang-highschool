# 📊 인구 데이터 시각화

> 전국과 제주 지역의 연령별 남녀 인구를 비교하고, 성별 인구 차이가 크게 나타나는 연령을 찾은 AI 동아리 데이터 시각화 프로젝트입니다.

CSV에 포함된 지역·연령·성별 인구를 분석 가능한 숫자로 변환하고, 인구 피라미드와 차이 그래프를 이용해 데이터의 특징을 표현했습니다.

<br>

| Item | Description |

## 🎯 분석 목표

* 전국의 연령별 남녀 인구 분포를 시각적으로 비교합니다.
* 지역 조건을 적용해 제주 인구만 별도로 분석합니다.
* 남자와 여자 인구의 차이가 가장 큰 연령을 찾습니다.
* 데이터에 맞는 그래프를 선택하고 시각화가 전달하는 의미를 해석합니다.

<br>

## 📊 데이터 불러오기

```python
df_pop = pd.read_csv(
    "korea_pop.csv",
    encoding="cp949",
    thousands=",",
)
```

* `cp949`로 한글 지역명이 포함된 CSV를 읽었습니다.
* `thousands=','` 옵션으로 천 단위 쉼표를 제거했습니다.
* 연령별 인구수를 문자열이 아닌 수치로 계산할 수 있도록 준비했습니다.

원본 CSV는 저장소에 포함하지 않았습니다. 재실행할 때 행정안전부 주민등록 인구통계에서 연령별 인구 자료를 내려받아 `korea_pop.csv`라는 이름으로 Google Colab에 업로드해야 합니다.

<br>

## 🔄 분석 과정

```text
인구 CSV 업로드
      ↓
지역·연령·성별 열 확인
      ↓
전국 남녀 인구 배열 생성
      ↓
인구 피라미드와 차이 그래프 작성
      ↓
제주 지역 행 선택
      ↓
연령별 남녀 차이 계산
      ↓
차이가 가장 큰 연령 출력
```

<br>

## 📈 시각화

### 전국 연령별 인구

남자와 여자 인구를 연령별로 나눠 표현해 전체 인구 구조와 성별 분포를 비교했습니다.

### 남녀 인구 차이

같은 연령의 남자 인구와 여자 인구 차를 계산하고 빨간색 막대그래프로 표시했습니다.

### 제주 지역 분석

제주 데이터만 선택한 뒤 남자가 더 많은 연령과 여자가 더 많은 연령을 각각 찾아, 가장 큰 차이와 해당 나이를 출력했습니다.

<br>

## ⚠️ 분석 범위와 한계

* 한 시점의 인구 자료만 사용해 인구 구조의 시간적 변화는 확인하지 않습니다.
* 절대 인원 차이는 지역 전체 인구 규모의 영향을 받습니다.
* 성별을 데이터에 제공된 남자·여자 두 범주로만 비교합니다.
* 노트북은 Google Colab 파일 업로드와 한글 폰트 설정을 전제로 작성되었습니다.

<br>

# DNA 컴퓨팅과 데이터 저장

DNA 염기서열을 계산과 저장 매체로 활용하는 원리를 컴퓨터공학 관점에서 조사한 생활과 과학 주제탐구 소논문입니다.

## 개요

- 소속: 부산중앙고등학교 생활과 과학 주제탐구
- 시기: 2024.11
- 분야: DNA Computing, Encoding, Parallelism, Storage

## 탐구 내용

- 이진 정보를 DNA의 네 염기서열로 변환하는 인코딩 방식을 조사했습니다.
- 다수의 DNA 분자가 동시에 반응하는 병렬 계산의 특징을 정리했습니다.
- 작은 물리적 부피에 많은 정보를 보관하는 고밀도 저장 가능성을 살펴봤습니다.
- 입출력 속도, 원하는 정보의 검색, 오류와 비용 등 실제 컴퓨팅 시스템이 되기 위해 해결할 과제를 분석했습니다.

## 배운 점

컴퓨팅 시스템은 실리콘 반도체만으로 구성된다는 관점을 넓히고, 정보 표현·연산·저장이라는 컴퓨터공학의 기본 개념을 생명과학 기술에도 적용해 볼 수 있었습니다.

# 최저임금과 물가 예측

연도별 최저임금과 소비자물가지수 데이터를 결합해 두 지표의 관계를 분석하고 물가 변화 방향을 예측한 데이터 프로젝트입니다.

## 주요 작업

- KOSIS 소비자물가지수와 연도별 최저임금 데이터를 수집했습니다.
- 분석에 필요한 연도와 지표를 기준으로 데이터를 정제하고 결합했습니다.
- 두 변수의 변화와 관계를 시각화하고 회귀 기반 예측 과정을 실습했습니다.
- 예측 결과를 인과관계로 단정하지 않고 데이터의 범위와 한계를 함께 검토했습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Regression` · `Public Data`

## 배운 점

서로 다른 출처의 공공데이터를 공통 기준으로 결합하고, 분석 결과와 해석의 한계를 구분하는 과정을 경험했습니다.

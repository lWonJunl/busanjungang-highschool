# 경사하강법과 SDGs 정책 방향 탐구

AI 모델의 핵심 최적화 방법인 경사하강법을 이해하고, 정책 데이터 예측에 적용할 가능성을 살펴본 주제탐구 소논문입니다.

## 개요

- 소속: 부산중앙고등학교 창의융합주간 주제탐구
- 기간: 2024.07.08–2024.07.12
- 분야: AI 최적화, 정책 데이터, SDGs

## 탐구 내용

- 평균제곱오차와 손실함수가 모델의 오차를 표현하는 방법을 정리했습니다.
- 가중치 갱신, 기울기와 학습률의 관계를 경사하강법의 수학적 흐름으로 살펴봤습니다.
- 지역 최솟값과 학습률 설정의 한계를 검토했습니다.
- SDGs 정책 효과를 데이터로 예측할 때 경사하강법을 활용할 가능성을 문헌과 사례를 통해 탐구했습니다.

## 배운 점

AI 모델의 결과만 사용하는 데서 벗어나 모델이 오차를 줄이며 학습하는 과정을 수학과 알고리즘 관점에서 이해했습니다. 이 문서는 연구 내용을 포트폴리오용으로 요약한 공개 자료입니다.

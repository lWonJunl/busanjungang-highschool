# 인구 데이터 시각화

연령별 인구 데이터를 가공하고 분포를 그래프로 표현해 지역과 연령 구조를 이해한 데이터 시각화 프로젝트입니다.

## 주요 작업

- 인구 데이터의 행과 열 구조를 확인하고 필요한 범위를 선택했습니다.
- 문자열과 수치 데이터를 분석 가능한 형태로 변환했습니다.
- NumPy와 Pandas로 연령별 값을 집계했습니다.
- 분포를 그래프로 표현해 인구 구조를 비교했습니다.

## 기술

`Python` · `Jupyter Notebook` · `NumPy` · `Pandas` · `Visualization`

# 2030년 서울 기온 예측

장기간의 서울 기온 데이터를 정리하고 회귀 모델을 이용해 2030년 평균기온을 예측한 AI 프로젝트입니다.

## 주요 작업

- 연도별 서울 기온 데이터의 구조와 결측 여부를 확인했습니다.
- 학습에 사용할 특성과 목표값을 정리하고 훈련 데이터를 구성했습니다.
- 회귀 모델을 학습해 미래 평균기온을 예측했습니다.
- 실제 데이터의 흐름과 예측 결과를 그래프로 비교했습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Regression` · `Matplotlib`

## 배운 점

시계열 성격을 가진 데이터를 단순 회귀로 다룰 때 얻을 수 있는 결과와 장기 예측이 갖는 한계를 함께 확인했습니다.

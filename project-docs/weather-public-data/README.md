# 기상 공공데이터 처리

공공 기상 자료를 불러와 분석에 필요한 형태로 정제·집계·시각화하는 전체 흐름을 실습한 데이터 프로젝트입니다.

## 주요 작업

- 공공데이터 파일을 읽고 열 이름, 자료형과 결측값을 확인했습니다.
- 분석 목적에 맞는 행과 열을 선택하고 값을 정제했습니다.
- 조건별 집계와 기초 통계로 데이터의 특징을 파악했습니다.
- 처리 결과를 그래프로 표현하고 해석했습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Public Data` · `Weather Data`

분석 모델보다 먼저 데이터의 구조와 품질을 확인하고 일관된 전처리 과정을 만드는 것이 중요하다는 점을 익혔습니다.

# 월별 불쾌지수 분석

기상개황 자료에서 기온과 습도 정보를 가공해 월별 불쾌지수를 계산하고 계절별 변화를 비교한 데이터 분석 프로젝트입니다.

## 주요 작업

- 기상개황 자료에서 분석에 필요한 기온과 습도 열을 선택했습니다.
- 월별 값을 정제하고 불쾌지수 계산식을 적용했습니다.
- 계산 결과를 표와 그래프로 표현해 월별 차이를 비교했습니다.
- 지수의 의미와 실제 체감 환경을 해석했습니다.

## 기술

`Python` · `Jupyter Notebook` · `Pandas` · `Matplotlib` · `Weather Data`
